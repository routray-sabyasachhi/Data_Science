# Python for Data Science

## Why study this
Python is a readable general-purpose language with a mature ecosystem for analysis, automation, modeling, and deployment. The existing PDFs in this folder can supplement the sequence below.

## Topics and subtopics
- Setup and execution: interpreter, scripts, REPL, notebooks, virtual environments, package installation, imports
- Syntax: indentation, comments, names, literals, operators, expressions, statements
- Core types: integers, floats, booleans, strings, `None`, type conversion, mutability and identity
- Collections: lists, tuples, dictionaries, sets, indexing, slicing, comprehensions, nested structures
- Control flow: conditionals, loops, loop control, pattern matching overview
- Functions: parameters, defaults, positional/keyword arguments, scope, return values, lambda, recursion, annotations
- Strings and text: formatting, methods, Unicode, regular expressions, parsing
- Errors: exceptions, raising, handling, custom exceptions, debugging tracebacks
- Files and serialization: paths, context managers, text/binary IO, CSV, JSON, pickle risks
- Modules and packages: imports, package layout, `__name__`, standard library, third-party libraries
- Object-oriented programming: classes, instances, methods, inheritance, composition, properties, dataclasses, protocols overview
- Iteration: iterables, iterators, generators, lazy evaluation
- Functional patterns: `map`, `filter`, comprehensions, closures, higher-order functions
- Useful standard library: `pathlib`, `collections`, `itertools`, `functools`, `datetime`, `re`, `statistics`, `logging`, `argparse`
- Numerical computing: NumPy arrays, shapes, dtypes, vectorization, broadcasting, indexing, random generation, linear algebra basics
- Tabular analysis: pandas Series/DataFrames, importing, selecting, filtering, missing values, joins, grouping, reshaping, dates, export
- Visualization: matplotlib and seaborn fundamentals; chart selection and labels
- Quality: PEP 8, formatting, linting, type hints, tests, profiling, documentation, reusable functions
- Advanced awareness: concurrency concepts, async IO, memory/performance, C extensions only as needed
- Data science workflow: notebooks for exploration, scripts/packages for reusable work, configuration and reproducible seeds
