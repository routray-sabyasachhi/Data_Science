# Deployment and MLOps

## Why study this
A model only creates value when it works reliably in its intended setting. Deployment and MLOps connect experimentation to tested, monitored, maintainable services and batch workflows.

## Topics and subtopics
- Production requirements: latency, throughput, availability, accuracy, privacy, cost, rollback
- Packaging: reusable modules, dependency locking, configuration, environment separation
- Serving patterns: batch scoring, online API, streaming inference, embedded/on-device concepts
- APIs: request/response schemas, validation, versioning, authentication, error handling
- Model artifacts: serialization formats, registries, metadata, lineage, reproducibility
- Testing: unit, integration, contract, data, model, load, security, regression tests
- CI/CD: lint/test/build, artifact promotion, deployment strategies, rollback
- Monitoring: service health, latency, failures, data quality, drift, performance, feedback loops
- Retraining: triggers, schedules, validation gates, human approval, champion/challenger
- Experiment tracking: parameters, metrics, code/data versions, model comparison
- Governance: documentation/model cards, approvals, audit trails, access, retention
- Reliability: logging, metrics, traces, alerting, incident response, SLAs/SLOs
- Security: secrets, dependency risk, input validation, model/data access, supply chain awareness
- Operational tradeoffs: batch vs real-time, model complexity vs maintenance, cost controls
