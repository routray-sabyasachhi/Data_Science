# Big Data and Cloud Foundations

## Why study this
When data or workloads outgrow a laptop, distributed and cloud tools provide scalable storage and compute. Learn the concepts first; platform details depend on your employer and project.

## Topics and subtopics
- Scale concepts: vertical/horizontal scaling, throughput, latency, cost, bottlenecks
- Distributed systems: partitioning, replication, fault tolerance, consistency, retries, idempotency
- File systems and object storage: buckets, keys, lifecycle, permissions, formats, partitions
- Distributed processing: map/reduce concepts, Spark DataFrames, lazy execution, shuffles, joins, partitions
- Data lake/warehouse/lakehouse architecture and tradeoffs
- Cloud concepts: regions/zones, compute, storage, networking, IAM, managed services, billing
- Containers: images, Dockerfiles, registries, volumes, networking, reproducible runtime
- Orchestration awareness: workflow schedulers, DAGs, dependencies, retries, backfills
- Streaming concepts: event brokers, topics, partitions, consumer groups, windows, delivery semantics
- Security and operations: identity, secrets, encryption, logs, budgets, monitoring
- Performance and cost: resource sizing, query optimization, caching, data locality, autoscaling
- Platform awareness: AWS/Azure/GCP equivalents; learn one platform deeply when needed
