# Deep Learning and Modern AI

## Why study this
Neural methods are valuable for images, audio, language, and other complex inputs. Study them after core math, probability, Python, and classical ML; choose specializations based on actual problems.

## Topics and subtopics
- Prerequisites: vectors/matrices, derivatives, probability, optimization, generalization
- Neural network basics: neurons, layers, activations, parameters, forward pass, loss functions
- Training: backpropagation, gradient descent variants, batches, epochs, initialization, learning-rate schedules
- Regularization: weight decay, dropout, early stopping, augmentation, normalization layers
- Architectures: MLPs, CNNs, recurrent networks, attention, transformers
- Framework practice: tensors, autograd, datasets/dataloaders, device placement, training/evaluation loops, checkpoints
- Evaluation: splits, baselines, metrics, error analysis, calibration, compute budgeting
- Computer vision: image representation, convolution, classification, detection, segmentation, transfer learning
- NLP: tokenization, embeddings, language models, sequence tasks, transformers, fine-tuning, retrieval-augmented generation concepts
- Generative models: autoregressive, GAN, VAE, diffusion concepts and evaluation risks
- Audio/time signals: spectrograms, sequence modeling, speech task overview
- Foundation models: pretraining, prompting, fine-tuning, embeddings, retrieval, tool use, context limits, hallucination evaluation
- Reinforcement learning overview: states/actions/rewards, policies, value, exploration, applications and limitations
- Efficiency: GPU basics, batching, mixed precision, quantization, distillation, parameter-efficient fine-tuning
- Safety: data provenance, privacy, bias, misuse, evaluation, human oversight
