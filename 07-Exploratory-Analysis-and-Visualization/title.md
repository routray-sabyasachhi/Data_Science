# Exploratory Analysis and Visualization

## Why study this
Exploration reveals data quality issues, useful patterns, and questions worth testing. Clear visualizations help people understand evidence and make sound decisions.

## Topics and subtopics
- Question framing: audience, decision, unit of analysis, hypotheses, success criteria
- Data inspection: dimensions, types, ranges, uniqueness, missingness, duplicates, distributions
- Univariate analysis: numeric and categorical summaries, skew, tails, anomalies
- Bivariate/multivariate analysis: group comparisons, relationships, interactions, confounding, stratification
- Data cleaning and transformations: parsing, scaling, log transforms, binning, date/time and geographic handling
- Visualization grammar: marks, channels, scales, axes, color, labels, facets, annotations
- Chart choice: comparison, distribution, relationship, composition, time, geography; avoid misleading forms
- Core plots: bars, lines, scatter, histograms, density, box/violin, heatmaps, maps, small multiples
- Design: hierarchy, accessibility, color vision, contrast, uncertainty, clutter, truthful axes
- Tools: matplotlib, seaborn, plotly concepts, dashboarding concepts (Tableau/Power BI)
- EDA workflow: question-led exploration, log decisions, separate exploration from confirmatory analysis
- Dashboard design: metrics, filters, layout, refresh, performance, user testing
- Reporting: captions, annotations, source notes, definitions, limitations
