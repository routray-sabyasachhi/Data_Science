# Data Science Learning Roadmap

The detailed, navigable roadmap is now maintained in the root [README.md](./README.md). It links all 15 subjects, explains prerequisite relationships, and describes core and advanced study paths.

Each numbered subject folder contains an index `README.md` and an ordered set of numbered topic folders. Every topic folder has a detailed `README.md` with prerequisites, a checklist, concepts, practical work, exercises, outcomes, and completion criteria. Original subject `title.md` notes and the Python course PDFs remain in place.

## Study order

1. Computing and tools
2. Python
3. Mathematics
4. Statistics and probability
5. SQL and databases
6. Data collection and engineering
7. Exploratory analysis and visualization
8. Machine learning
9. Deep learning and AI (advanced / role-dependent)
10. Time series and experimental methods (specialization)
11. Big data and cloud (scale-dependent)
12. Deployment and MLOps (production-focused)
13. Communication and product analytics (apply throughout)
14. Responsible data science (apply throughout)
15. Projects and portfolio (build progressively)

See [PROGRESS.md](./PROGRESS.md) to track study and project work, and [reference.md](./reference.md) for books and websites.
