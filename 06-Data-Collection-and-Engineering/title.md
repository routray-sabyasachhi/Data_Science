# Data Collection and Engineering

## Why study this
Reliable analysis begins with data that is collected, documented, validated, transformed, and stored responsibly. Data engineering principles make these steps repeatable and prevent silent errors.

## Topics and subtopics
- Data lifecycle and architecture: source, ingestion, raw/staged/curated layers, consumers, lineage
- Data sources: files, databases, APIs, surveys, sensors, logs, public data; licenses and provenance
- APIs: HTTP methods, REST patterns, pagination, filtering, JSON, authentication, rate limits, retries, status codes
- Web data: HTML structure, robots and terms awareness, scraping limits, structured extraction
- Acquisition issues: sampling, coverage, selection bias, consent, timestamps, identifiers
- Data quality: completeness, validity, uniqueness, consistency, timeliness, accuracy; data contracts
- Cleaning: schema checks, types, missing values, duplicates, outliers, units, normalization, encoding, entity resolution
- Transformation: joins, aggregation, reshaping, feature creation, idempotence
- Formats and storage: CSV, JSON, Parquet, Arrow awareness, compression, partitioning, schemas
- ETL/ELT: extract/load/transform tradeoffs, staging, orchestration concepts, dependencies, scheduling
- Batch and streaming: events, windows, late data, delivery guarantees concepts
- Pipelines: modularity, retries, checkpoints, logging, alerting, backfills, failure recovery
- Validation: unit/data tests, schema validation, reconciliation, invariants, drift checks
- Warehousing/lakes: OLTP vs OLAP, data lake, warehouse, lakehouse concepts, dimensional modeling
- Governance: catalog, metadata, ownership, retention, access control, lineage
- Security: secrets management, encryption awareness, least privilege, safe handling of personal data
