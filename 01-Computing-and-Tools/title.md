# Computing and Developer Tools

## Why study this
Data work depends on being able to run programs reliably, inspect files, reproduce environments, track changes, and collaborate. These tools prevent avoidable friction and make analysis reproducible.

## Topics and subtopics
- Computer and OS basics: filesystems, paths, extensions, permissions, processes, memory, CPU, environment variables
- Terminal: navigation, listing, creating and moving files, pipes, redirection, search, exit codes, quoting, shell scripts
- Editors and IDEs: projects, debugging, formatting, linting, integrated terminal, extensions
- Git: repositories, working tree, staging, commits, diffs, branches, merge/rebase concepts, remotes, conflicts, tags, `.gitignore`, recovery
- Git hosting and collaboration: README, issues, pull requests, review, releases, licenses, secrets hygiene
- Environments: virtual environments, dependency installation, pinned versions, lockfiles, `pip`, conda concepts, reproducibility
- Jupyter: kernels, cells, execution order, markdown, outputs, restart/run-all, notebook cleanliness, export
- Data formats: text, CSV, JSON, YAML, Parquet, Excel, images; encodings, delimiters, schemas
- Testing and debugging basics: tracebacks, breakpoints, assertions, small checks, logging
- Documentation: Markdown, docstrings, project structure, reproducible instructions
- Basic networking: HTTP, URLs, APIs, status codes, authentication concepts; protect credentials
