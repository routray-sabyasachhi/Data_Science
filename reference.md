# Data Science References

Use the books for structured learning and the websites for current tool details, exercises, and deeper reference. Book editions and software documentation can change; check the publisher or official project site before buying or following version-specific instructions. Choose one primary text per subject rather than trying to read every item cover to cover.

## Computing and tools
- *The Linux Command Line* — William Shotts (shell and command-line foundations).
- *Pro Git* — Scott Chacon and Ben Straub, free online: https://git-scm.com/book/en/v2
- Official Git reference: https://git-scm.com/docs
- Jupyter documentation: https://docs.jupyter.org/

## Python
- *Python Crash Course* — Eric Matthes (beginner-friendly programming).
- *Fluent Python* — Luciano Ramalho (intermediate/advanced language features).
- Official Python tutorial and library reference: https://docs.python.org/3/tutorial/
- Python Packaging User Guide: https://packaging.python.org/
- NumPy user guide: https://numpy.org/doc/stable/user/
- pandas user guide: https://pandas.pydata.org/docs/user_guide/
- Matplotlib tutorials: https://matplotlib.org/stable/tutorials/

## Mathematics
- *Mathematics for Machine Learning* — Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong (linear algebra, calculus, probability; free online edition at https://mml-book.github.io/).
- *Introduction to Linear Algebra* — Gilbert Strang.
- *Calculus* — James Stewart (or another standard calculus text).
- MIT OpenCourseWare, Linear Algebra: https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/
- 3Blue1Brown, Essence of Linear Algebra (visual intuition): https://www.3blue1brown.com/topics/linear-algebra

## Statistics and probability
- *OpenIntro Statistics*, free resources and book: https://www.openintro.org/book/os/
- *Introduction to Modern Statistics*, free online: https://openintrostat.github.io/ims/
- *Statistical Inference via Data Science* — ModernDive: https://moderndive.com/
- *All of Statistics* — Larry Wasserman (more mathematical reference).
- *Practical Statistics for Data Scientists* — Peter Bruce, Andrew Bruce, Peter Gedeck (applied reference).
- Khan Academy probability and statistics: https://www.khanacademy.org/math/statistics-probability

## SQL and databases
- *Learning SQL* — Alan Beaulieu.
- *SQL for Data Scientists* — Renee M. P. Teate.
- PostgreSQL official tutorial: https://www.postgresql.org/docs/current/tutorial.html
- PostgreSQL SQL language reference: https://www.postgresql.org/docs/current/sql.html
- SQLBolt interactive lessons: https://sqlbolt.com/

## Data collection and engineering
- *Fundamentals of Data Engineering* — Joe Reis and Matt Housley.
- *Designing Data-Intensive Applications* — Martin Kleppmann (systems concepts; advanced).
- Apache Airflow documentation: https://airflow.apache.org/docs/
- Apache Spark documentation: https://spark.apache.org/docs/latest/
- Great Expectations documentation: https://docs.greatexpectations.io/
- W3C data on the web best practices: https://www.w3.org/TR/dwbp/

## Exploratory analysis and visualization
- *The Visual Display of Quantitative Information* — Edward Tufte.
- *Storytelling with Data* — Cole Nussbaumer Knaflic.
- *Fundamentals of Data Visualization* — Claus O. Wilke, free online: https://clauswilke.com/dataviz/
- *Data Visualization: A Practical Introduction* — Kieran Healy, free online: https://socviz.co/
- Seaborn tutorial: https://seaborn.pydata.org/tutorial.html
- Tableau free training: https://www.tableau.com/learn/training
- Microsoft Power BI learning: https://learn.microsoft.com/power-bi/

## Machine learning
- *An Introduction to Statistical Learning* — Gareth James, Daniela Witten, Trevor Hastie, Robert Tibshirani, and Jonathan Taylor; free editions and labs: https://www.statlearning.com/
- *The Elements of Statistical Learning* — Trevor Hastie, Robert Tibshirani, Jerome Friedman; free online: https://hastie.su.domains/ElemStatLearn/
- *Hands-On Machine Learning with Scikit-Learn, Keras & TensorFlow* — Aurélien Géron (practical; check edition compatibility).
- Scikit-learn user guide: https://scikit-learn.org/stable/user_guide.html
- Stanford CS229 notes: https://cs229.stanford.edu/main_notes.pdf

## Deep learning and AI
- *Deep Learning* — Ian Goodfellow, Yoshua Bengio, Aaron Courville; free online: https://www.deeplearningbook.org/
- *Dive into Deep Learning* — Aston Zhang, Zachary C. Lipton, Mu Li, and Alex J. Smola; free online: https://d2l.ai/
- *Understanding Deep Learning* — Simon J. D. Prince; free online: https://udlbook.github.io/udlbook/
- PyTorch tutorials: https://pytorch.org/tutorials/
- TensorFlow tutorials: https://www.tensorflow.org/tutorials
- Hugging Face course: https://huggingface.co/learn
- Stanford CS231n course materials (vision): https://cs231n.stanford.edu/

## Time series, experiments, and causal methods
- *Forecasting: Principles and Practice* — Rob J Hyndman and George Athanasopoulos, free online: https://otexts.com/fpp3/
- *Causal Inference: The Mixtape* — Scott Cunningham, free online: https://mixtape.scunning.com/
- *Causal Inference: What If* — Miguel Hernán and James Robins, free online: https://www.hsph.harvard.edu/miguel-hernan/causal-inference-book/
- Statsig experimentation guides: https://www.statsig.com/experimentation
- Google experimentation resources: https://research.google/ (search for experimentation papers and materials)
