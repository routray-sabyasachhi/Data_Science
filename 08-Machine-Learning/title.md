# Classical Machine Learning

## Why study this
Machine learning finds patterns that can support prediction, ranking, segmentation, and decisions. Learning the full workflow matters as much as knowing algorithms: leakage or poor evaluation can make an impressive score useless.

## Topics and subtopics
- Problem framing: prediction target, unit, horizon, constraints, baseline, cost of errors
- Workflow: train/validation/test splits, cross-validation, preprocessing pipelines, reproducibility
- Data leakage: target leakage, temporal leakage, preprocessing leakage, group leakage
- Features: numeric/categorical/text/date features, encoding, scaling, imputation, feature selection, domain features
- Supervised learning: regression vs classification, linear regression, logistic regression, k-nearest neighbors
- Regularization: ridge, lasso, elastic net, bias-variance tradeoff
- Trees and ensembles: decision trees, random forests, bagging, gradient boosting, XGBoost/LightGBM concepts
- Margin methods: support vector machines, kernels intuition
- Probabilistic classification: Naive Bayes, calibration, decision thresholds
- Imbalanced data: stratified splits, class weights, resampling, precision-recall tradeoffs
- Metrics: MAE/MSE/RMSE, R² limits, confusion matrix, precision, recall, F1, ROC-AUC, PR-AUC, log loss
- Model selection: hyperparameter search, nested CV awareness, learning curves, validation strategy
- Interpretation: coefficients, permutation importance, partial dependence, SHAP concepts, explanation limits
- Unsupervised learning: clustering (k-means, hierarchical, DBSCAN), scaling, distance, cluster evaluation
- Dimensionality reduction: PCA, t-SNE/UMAP awareness, interpretation limits
- Anomaly detection and recommendation basics
- Uncertainty and robustness: prediction intervals, calibration, subgroup performance, distribution shift
- Responsible modeling: fairness checks, explainability needs, human review, impact assessment
